## Struktur repo

| Folder | Isi |
|---|---|
| `Pertemuan_1/` | Pengenalan media & konversi format (Media_Asli, Media_Hasil) |
| `Pertemuan_2/` | Representasi teks & ukuran file (`teks.py`, `teks2.py`, `hitung.py`) |
| `Pertemuan_3/` | Kompresi lossless: RLE (`rle.py`) dan kode Huffman (`hufman.py`) |
| `Pertemuan_4/` | FFmpeg: konversi WAV -> MP3/AAC/FLAC (`batch_encoding.py`, File_wav/) |
| `Pertemuan_5/` | Pillow: konversi warna, grayscale, histogram, kompresi JPEG, resizing (`praktikum_5.py`) |
| `Pertemuan_6/` | Analisis kualitas kompresi JPEG vs WebP: PSNR & SSIM (`praktikum_6.py`, `hasil/perbandingan_kompresi.csv`) |
| `Pertemuan_7/` | Analisis video: struktur GOP, frame differencing, redundansi temporal (`pertemuan7.py`, `frame_differencing.py`, `frames.json`) |
| `UTS/` | **Ujian Tengaah Semester**: kode verifikasi Soal 1-5, bukti hasil run (`hasil/output_soal*.txt`), salinan bukti Pertemuan 4-7 (`hasil/bukti/`) — lihat `UTS/README.md` |
