================================================================
SOAL 1 - Ukuran file audio PCM mono, 5 s, 44.100 Hz, 16-bit
================================================================
Rumus  : Ukuran = sample_rate x durasi x bit_depth x jumlah_kanal
Jumlah sampel = 44100 x 5 s              = 220,500 sampel
Total bit     = 220,500 x 16 bit x 1 kanal = 3,528,000 bit
Ukuran file   = 3,528,000 / 8            = 441,000 byte (~430.7 KiB)

================================================================
SOAL 2 - RLE, Huffman, dan rasio kompresi untuk 'AAAABBBCCD'
================================================================
Data asli  : AAAABBBCCD  (10 karakter = 80 bit)
Hasil RLE  : 4A3B2C1D  (8 karakter = 64 bit)
Rasio RLE  : 80/64 = 1.25 : 1

Simbol  Frekuensi  Kode    Panjang  Total bit
  A        4        0       1        4
  B        3        10      2        6
  C        2        111     3        6
  D        1        110     3        3

Rata-rata panjang kode = 19/10 = 1.90 bit/simbol
Entropi sumber H       = 1.8464 bit/simbol (efisiensi kode = 97.2%)
Total bit Huffman      = 19 bit
Rasio Huffman          = 80/19 = 4.21 : 1
Catatan: menukar kode C/D antar-cabang tetap valid, total bit tidak berubah.
